# Translation Dictionary

Established terminology for consistent localisation of generic plugin strings.

## Terms kept in English

These terms are not translated. Use the English form in all locales. Inflect grammatically
(articles, case endings, plurals) as the target language requires, but keep the root word.

| Term | Notes |
| --- | --- |
| `agent` | An AI agent instance |
| `BEVE` | Agent checkpoint file format — shown in `prune` output |
| `MMIO` | Memory-mapped state file — shown in `prune` output |
| `UUID` | Universally unique identifier |
| `PID` | Process identifier |
